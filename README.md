# Customer Behavior Analysis

## Overview

An end-to-end data analytics project exploring customer purchasing behavior, demographics, and spending patterns.

This project extends my original customer behavior analysis by incorporating **Python, SQL, Power BI, and business reporting** to demonstrate the complete analytics workflow from raw data to actionable insights.

**Workflow:** Raw Data → Python EDA → Data Cleaning → SQL Analysis → Power BI Dashboard → Business Insights

---

## Dataset

The dataset contains customer-level information covering areas such as:

* Customer demographics
* Purchase behavior
* Product categories
* Purchase frequency
* Spending
* Discounts and promotions
* Subscription status
* Customer ratings

## Steps

### 1. Data Loading & EDA

Loaded the raw dataset into Python and explored its structure, distributions, relationships, and potential data quality issues.

### 2. Data Cleaning

Handled missing values, duplicates, inconsistent values, data types, and other quality issues to create an analysis-ready dataset.

### 3. SQL Analysis

Loaded the cleaned data into a relational database and used SQL to answer business-focused questions using aggregations, joins, CTEs, `CASE WHEN`, and window functions.

### 4. Power BI Dashboard

Built an interactive dashboard to analyze customer segments, purchasing behavior, spending patterns, and key KPIs.

### 5. Reporting & Presentation

Translated the analysis into a written report and business-focused presentation highlighting key findings and recommendations.

## How to Run

1. Clone the repository.
2. Install the required Python libraries.
3. Run the Jupyter Notebook for EDA and data cleaning.
4. Import the cleaned dataset into PostgreSQL/MySQL/SQL Server.
5. Run the SQL queries.
6. Open the `.pbix` file in Power BI Desktop.
